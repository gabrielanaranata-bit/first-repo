# 100Hires Portfolio Project Setup

## Overview

This repository documents my setup process for the first step of the 100Hires portfolio project. The goal of this step was to install the required tools, create a public GitHub repository, connect the repository to Cursor, and document the process in this README file.

This was my first time using Cursor and working with a GitHub repository in this way, so the process was new and challenging for me. However, I used this experience as an opportunity to learn, troubleshoot, and complete the setup step by step.

---

## Tools I Installed

The tools I successfully installed and set up are:

1. Cursor IDE
2. Claude Code add-on in Cursor
3. Codex add-on in Cursor
4. GitHub repository connected to Cursor

---

## Steps I Completed

### 1. Installed Cursor IDE

I downloaded Cursor from the official website:

https://cursor.com/

After the installation was completed, I signed up and logged in to Cursor using my Gmail account.

---

### 2. Opened Cursor and Created a Project Folder

After logging in to Cursor, I clicked **File** in the top-left corner and selected **Open Editor Window**.

After entering the editor window, I created a new folder in File Explorer. Then, I went back to Cursor and clicked **Open Project** to open the folder that I had created.

---

### 3. Installed Claude Code and Codex Add-ons

To open the Extensions section in Cursor, I pressed:

`Ctrl + Shift + X`

Another way to open Extensions is by clicking the square-shaped Extensions icon on the left side of Cursor.

After that, I searched for:

`Claude Code`

and installed the Claude Code add-on.

Then, I searched for:

`Codex`

and installed the Codex add-on.

---

### 4. Created a GitHub Repository

To create the repository, I followed these steps:

1. Opened GitHub
2. Logged in or signed up to GitHub
3. Clicked the **+** button in the top-right corner
4. Clicked **New repository**
5. Added a repository name
6. Selected **Public**
7. Checked **Add a README file**
8. Clicked **Create repository**

---

### 5. Cloned the GitHub Repository to Cursor

After creating the repository, I cloned it to Cursor by following these steps:

1. Opened the repository on GitHub
2. Clicked the green **Code** button
3. Copied the HTTPS repository link
4. Opened Cursor
5. Made sure **Auto Save** was turned on by clicking **File** and checking **Auto Save**
6. Pressed `Ctrl + Shift + P`
7. Typed `Git: Clone`
8. Pasted the repository link
9. Chose a folder on my laptop to save the project
10. Clicked **Open** after the cloning process was completed
11. Followed the login process when Cursor asked for GitHub permission

After the repository was successfully cloned, I was able to edit the `README.md` file in Cursor.

---

### 6. Edited the README.md File

After opening the cloned repository in Cursor, I edited the `README.md` file to document:

- The tools I installed
- The steps I completed
- The issues I ran into
- How I solved those issues

---

### 7. Committed and Pushed the Changes to GitHub

To commit and push the changes, I followed these steps:

1. Clicked the **Source Control** icon in the left sidebar of Cursor
2. Checked that the `README.md` file had changes
3. Wrote this commit message:

`Add README setup documentation`

4. Clicked **Commit**
5. Clicked **Sync Changes** or **Push**
6. Logged in to GitHub again if Cursor asked for permission

## Issues I Ran Into

Since I do not have a coding background, this was my first time using Cursor and working with GitHub in this way. At first, the process felt very unfamiliar to me.

The most difficult issues I faced were:

1. Understanding how to create a GitHub repository
2. Learning how to connect GitHub to Cursor
3. Cloning the GitHub repository into Cursor
4. Editing the README.md file inside Cursor
5. Committing and pushing the updated README.md file back to GitHub
6. Setting up the Claude Code add-on in Cursor

I also had trouble during the Claude Code setup. At first, I could not complete the installation smoothly, so I continued troubleshooting by restarting Cursor, checking the available extensions and model settings, opening a project folder first, and trying the installation process again.

After several attempts, I was able to complete the setup successfully.

---

## How I Solved the Issues

To solve the issues, I used several learning methods:

1. I watched YouTube tutorials
2. I asked AI tools for step-by-step guidance
3. I asked technical friends for help when I got stuck
4. I tried different troubleshooting steps directly in Cursor

At one point, I failed several times when trying to clone the repository from GitHub to Cursor. I had to open Task Manager, end the Cursor task, close the terminal window using `Ctrl + ~`, and restart the process from the beginning.

I also tried using the terminal and entering commands manually. Later, I realized that there was an easier way to commit changes directly through the Source Control panel in Cursor by writing a commit message and clicking **Commit**.

The main reasons I could not clone or push the repository at first were:

1. I had not enabled Auto Save
2. I spent too much time trying to find and type manual terminal commands, even though Cursor already had a simpler commit and push workflow through the interface
